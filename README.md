# Necrosis Forever

A fork of [Necrosis](https://github.com/CKNOEP/Necrosis), the warlock addon,
for the **WoW Forever** client only. It manages soul shards, stones, demons,
buffs, curses and spell timers, with a redesigned bottom banner.

## Install

1. Put the `NecrosisForever` folder in `_forever_/Interface/AddOns/`.
2. Disable the original **Necrosis** addon. Both use the same global names and
   the same saved settings (`NecrosisConfig`), so they can't run together.
   Your existing Necrosis settings carry over.

Other game versions (Retail, Classic, TBC, Wrath, ...) are not supported. Use
upstream Necrosis for those.
